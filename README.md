# EPL Check-In / POS System Capstone

Portfolio documentation for the EPL Check-In / POS System, a team-built capstone project for Portland State University's Electronics Prototyping Lab.

This repository summarizes the system architecture, technical stack, and documented contribution evidence for the project. The original application was built as a full-stack check-in, point-of-sale, inventory, customer, rental, locker, and transaction management system.

## Tech Stack

Python, FastAPI, SQLModel, PostgreSQL, Alembic, React, TypeScript, Vite, REST APIs, pytest, Playwright, Docker, Docker Compose, GitHub Actions.
